# AI Tutor - Frontend

The accessible Next.js web application for **AI Tutor**, built for neurodiverse school students (Standards 6–12).

## Features
- **Accessible UI:** High-contrast color palette, large tactile navigation buttons, and clear typography.
- **Planned Multimodal Controls:** Browser-based gaze navigation and voice interaction.
- **Backend Integration:** Real-time health monitoring and communication with the FastAPI backend.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.
