# Data Directory

This directory stores school textbook source materials and processed embeddings/indices.

## Directory Structure
- `data/raw/tn/`: Tamil Nadu State Board (SCERT) textbook PDFs (Standards 6 to 12).
- `data/raw/cbse/`: CBSE / NCERT textbook PDFs (Standards 6 to 12).
- `data/processed/`: Chunked documents, parsed metadata, and local indices.

> **Note:** Textbooks are proprietary to TN SCERT and NCERT respectively and are not included in this repository. Please download the required PDFs directly from the official portals into the respective `data/raw/` subdirectories.
